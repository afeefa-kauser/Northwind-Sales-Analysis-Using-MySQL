# Northwind-Sales-Analysis-Using-MySQL

## Project Overview

This project analyzes sales data from the Northwind database using MySQL. The objective was to extract meaningful business insights related to customer behavior, product performance, sales trends, and employee performance.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Database Tables Used

The analysis primarily uses the following tables:

* Customers
* Orders
* Order Details
* Products
* Employees

## Key Analysis Areas

The project covers the following business areas:

1. Customer sales performance
2. Product revenue analysis
3. Category performance
4. Monthly sales trends
5. Month-over-month sales growth
6. Customer ranking
7. Product ranking within categories
8. Cumulative sales analysis
9. Customer segmentation based on purchase frequency and value
10. Employee sales performance

## SQL Skills Demonstrated

This project demonstrates practical use of:

* SELECT statements
* JOIN operations
* Aggregate functions
* GROUP BY and ORDER BY
* Date functions
* CASE statements
* Common Table Expressions (CTEs)
* Window functions
* LAG()
* RANK()
* PARTITION BY
* Running totals

## Conclusion

The analysis provides insights into the customers, products, and employees that contribute most to sales performance. It also identifies monthly sales patterns, revenue growth, customer segments, and product performance across categories.
